Pricing Table – Task 12

A responsive pricing table with three plans, built with HTML5 and CSS3 as part of the Web Development Track (Level 1, Day 12).

Description

The page shows three pricing plans (Basic, Pro and Premium). Each card has a price, a feature list and a call-to-action button. The Pro plan is highlighted as the most popular choice.

Objective

Practice CSS Flexbox layouts and hover effects.

Tools
HTML5
CSS3
Features
Three pricing cards: Basic (R99/month), Pro (R199/month) and Premium (R399/month)
Highlighted "Most Popular" plan using a border, shadow, slight scale-up and badge
Flexbox layout with equal-height cards and buttons aligned at the bottom
Hover effects on cards (lift and shadow) and buttons (colour fill)
Responsive design: cards stack into one column on screens narrower than 800px
Project Structure
pricing-table/
├── index.html   # Page structure and plan content
├── style.css    # Layout, styling, hover effects and media query
└── README.md    # Project documentation
How to Run
Download or clone the project folder.
Keep index.html and style.css in the same folder.
Open index.html in any web browser.
Key CSS Concepts Used
Flexbox: display: flex, gap, justify-content, align-items and flex-grow to align the cards and keep the buttons at the bottom
Box shadow: box-shadow to give the cards depth and emphasise the featured plan
Transitions: transition with transform for smooth hover effects
Media queries: @media (max-width: 800px) to stack the cards on small screens
CSS variables: custom properties in :root for consistent colours
